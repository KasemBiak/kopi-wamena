# Kopi Wamena

Etalase digital bertema **Kopi Wamena** (Arabika Lembah Baliem, Papua) yang dilengkapi fitur rekomendasi rasa, filter kategori menu, serta alur pemesanan langsung ke WhatsApp.

## Live Demo
https://kasembiak.github.io/kopi-wamena/

## Struktur Folder
- `index.html` — Struktur halaman utama
- `css/style.css` — Gaya tampilan dan tata letak responsif
- `js/script.js` — Data menu, rekomendasi rasa, navigasi, dan integrasi WhatsApp

## Konteks Tugas
Dikembangkan untuk mata kuliah **Pemrograman Web** sebagai studi kasus *Income Generation Plan* berbasis katalog produk lokal.
